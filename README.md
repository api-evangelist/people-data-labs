# People Data Labs (people-data-labs)

People Data Labs provides a people data API for enriching and building people profiles at scale. The API provides access to professional profiles, company data, and identity resolution for B2B applications.

**APIs.json:** [https://raw.githubusercontent.com/api-evangelist/people-data-labs/refs/heads/main/apis.yml](https://raw.githubusercontent.com/api-evangelist/people-data-labs/refs/heads/main/apis.yml)

## APIs

### People Data Labs API

People enrichment and identity resolution API for building B2B applications with professional profile data, including person enrichment, person search, person identify, company enrichment, company search, IP enrichment, and job posting search.

- **Human URL:** [https://www.peopledatalabs.com/](https://www.peopledatalabs.com/)
- **Base URL:** `https://api.peopledatalabs.com/v5`
